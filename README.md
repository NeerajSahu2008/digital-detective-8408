# The Digital Detective

This repository contains my Diwali independent learning assignment, "The Digital Detective". In it I explore how a computer works by practising Terminal commands, learning about the operating system, converting numbers, and using Git and GitHub. The work is split into missions, and I document and commit each mission separately.
