# Mission 1 — Know your computer

## 1. Task / objective
Explain how a computer receives input, processes information, produces output and stores results (IPOS), and identify hardware, software and computer-based systems.

## 2. Work completed
I traced one activity using IPOS, listed four hardware items and four software examples and classified them, and listed three computer-based systems from everyday life.

### Task 1.1 — IPOS: searching the internet on my laptop

| Stage | What happens in my example | Hardware / component |
|-------|----------------------------|----------------------|
| Input | I type my search words on the keyboard and press Enter. | Keyboard, trackpad |
| Processing | The browser sends my request over the internet, and the processor handles the data using memory while the results come back. | CPU, RAM |
| Output | The search results page appears so I can read it. | Screen |
| Storage | The browser saves history and temporary files so pages load faster next time. | SSD |

**How the activity moves from input to storage:** My typing becomes data. The CPU processes that data with the help of RAM, the result is shown on the screen as output, and some of the data is saved on the SSD.

## 4. My understanding
IPOS stands for Input, Processing, Output and Storage. Every computer task follows this pattern: I give some input, the computer processes it, shows the output, and can store the result. Hardware is the physical parts of the computer, like the keyboard, screen and SSD. Software is the set of programs that tell the hardware what to do. Software has three types: operating system software manages the computer, application software helps me do tasks like browsing or coding, and utility software helps maintain or monitor the computer. Computer systems like ATMs, smart TVs and traffic signals also follow the same input-to-output idea, not just laptops.
