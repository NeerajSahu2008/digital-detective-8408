### Task 1.1 — IPOS: searching the internet on my laptop

| Stage | What happens in my example | Hardware / component |
|-------|----------------------------|----------------------|
| Input | I type my search words and press Enter. | Keyboard, trackpad |
| Processing | The browser sends my request, and the processor works on the data using memory while waiting for the results. | CPU, RAM |
| Output | The search results appear as a page I can read. | Screen |
| Storage | The browser saves history and temporary files so the page loads faster next time. | SSD |

How it moves: my typing becomes data, the CPU processes it, the result is shown on the screen, and some of the data is saved on the SSD.
